# Kebijakan Privasi — Jangan Nonton Sendiri

Terakhir diperbarui: 2 November 2026

Aplikasi "Jangan Nonton Sendiri" adalah alat pribadi milik pemilik channel untuk mengunggah video cerita horor animasi buatannya sendiri ke channel YouTube, akun Instagram, dan akun TikTok miliknya.

- Aplikasi ini hanya digunakan oleh pemilik channel, bukan untuk pengguna umum.
- Akses ke akun Google/YouTube hanya dipakai untuk mengunggah video dan mengisi judul/deskripsinya.
- Aplikasi ini tidak mengumpulkan, menjual, atau membagikan data pribadi siapa pun.
- Token akses disimpan secara terenkripsi sebagai GitHub Secrets dan hanya dipakai oleh proses unggah otomatis.
- Pemilik dapat mencabut akses kapan saja melalui https://myaccount.google.com/permissions

Penggunaan data dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Kontak: melalui halaman Issues repositori ini.
